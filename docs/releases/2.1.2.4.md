## 更新日志

版本：2.1.2.4
日期：2026-10-11

### 优化

- 应用版本检查改用用户系统的设备兼容更新接口，按当前 versionCode 和 Android SDK 选择可安装的已发布版本。
- 更新说明优先使用版本管理中的安全富文本和下载地址；接口异常时保留 GitHub Release API 与发布页兜底，避免过渡期间无法检查更新。
- 版本管理支持按版本开启强制更新，并可设置最低支持 versionCode；命中后更新弹窗不允许关闭。

### 修复

- 修复更新检查可能误选源码压缩包、校验文件或不匹配安装包的问题。
- 修复账号刷新时头像短暂闪动或重复加载的问题。
