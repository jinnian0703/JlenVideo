## JlenVideo 2.1.3.0 更新日志

### 新增

- **自动跳过片头片尾**　全屏播放时，点小窗左侧的剪刀图标，即可把当前位置设为片头结束或片尾开始。设置按影片和线路保存在本机，在线和离线播放共用。片尾按每集剩余时长计算，离线时只有下一集已下载才会自动切集。
- **影片弹幕与讨论**　弹幕跟随当前集的播放进度显示。竖屏可在播放页内发送，输入时播放器保持可见。全屏开启弹幕后，可直接在开关旁输入并发送。切到「讨论」即可聊整部影片，长按发言可举报。
- **电视直播**　首页在「最近更新」和推荐之间新增直播入口，支持按分类找频道、全屏观看和切换线路。

### 优化

- **下载选集**　详情页可直接打开下载面板，播放页可就地选集。支持按页或整条线路批量选择，已加入下载的剧集会自动跳过。下载管理按影片显示完成集数、合计速度和等待 Wi-Fi 等状态。
- **跨设备续播**　登录后，从详情、追剧或播放记录继续观看时，会比较本机与云端进度，优先恢复较新的线路、集数和播放位置。
- **播放失败提示**　在线播放失败时会显示错误，并向站点上报对应的影片、线路和集数，方便定位失效片源。
- **登录与搜索**　登录验证码可在弹窗内换图、重试。清空搜索记录后可点「撤销」恢复。
